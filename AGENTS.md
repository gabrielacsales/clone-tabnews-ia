# AGENTS.md

Orientações para agentes de IA trabalharem neste repositório.

## Sobre o projeto

`clone-tabnews-ia` - Implementação do [TabNews](https://tabnews.com.br) para o [curso.dev](https://curso.dev) utilizando agentes de IA.

## Stack Tecnológica

- **Next.js** (utilizando App Router)
- **React / React DOM**

## Estrutura do Projeto

- `app/`: Rotas, layouts e páginas da aplicação (Next.js App Router).
- `package.json`: Dependências e scripts do projeto.

## Comandos

- `npm run dev`: Inicia o servidor de desenvolvimento do Next.js (`next dev`).
- `npm run build`: Gera a build de produção da aplicação (`next build`).
- `npm run start`: Inicia o servidor de produção após o build (`next start`).
